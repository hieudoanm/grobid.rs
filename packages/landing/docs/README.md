# grobid.rs documentation

grobid.rs converts PDF articles to Markdown via GROBID TEI XML — making PDFs
AI-friendly on your own machine. Drop PDFs into a `pdf/` directory, run
`grobid`, and get clean Markdown with YAML-frontmatter metadata plus TEI XML
intermediates.

## Sections

- **Concepts** — repository layout, crates, and the conversion pipeline.
- **Guides** — the CLI, the GROBID service, TEI→Markdown rendering, local
  development, and releases.
